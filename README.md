# Yapay-Zek-Ajan-yla-Django-Test-retimi-ve-G-venlik-Analizi
Django tabanlı yazılım projelerinin kaynak kodlarını analiz ederek büyük dil modelleri (LLM) aracılığıyla otomatik Pytest testleri üreten, testleri doğrulayıp çalıştıran, kimlik doğrulama, yetkilendirme ve yapılandırma kaynaklı güvenlik sorunlarını inceleyen yapay zekâ destekli yazılım test ve güvenlik analiz sistemi.
